**School Management CRM System built using Django**

A complete School Management CRM System built using Django and Django REST Framework with authentication and CRUD operations for managing students and teachers.

🚀 **Features**
```text
🔐 Authentication System
User Registration
User Login & Logout
Django Authentication
```

👨‍🏫 **Teacher Management**
```text
Add Teacher
Update Teacher
Delete Teacher
View Teacher Details
```

🎓 **Student Management**
```text
Add Student
Update Student
Delete Student
Upload Student Images
View Student Details
```
🛠️ **Technologies Used**
```text
Python
Django
Django REST Framework (DRF)
SQLite (Django default internal database using migrations)
Bootstrap 5
HTML5
CSS3
Git & GitHub
```

📸 **Features Implemented**
```text
✅ CRUD Operations
✅ Dynamic Templates
✅ Image Upload
✅ Authentication System
✅ Role-Based Access
✅ Bootstrap UI
✅ Django Admin Panel
✅ Form Validation
```
